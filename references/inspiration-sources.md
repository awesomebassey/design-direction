# Inspiration Sources

Use references to calibrate taste and solve concrete design problems. Do not copy layouts blindly. Extract patterns, interaction choices, density, information hierarchy, and visual systems, then adapt them to the product.

## Broad Real-Site Inspiration

- [Recent Design](https://recent.design) — contemporary real websites.
- [Siteinspire](https://www.siteinspire.com) — curated web design references.
- [Land-book](https://land-book.com) — landing pages and marketing sites.
- [Posts Design](https://posts.design) — real UI and interface references.
- [Godly](https://godly.website) — high-polish website inspiration.
- [Awwwards](https://www.awwwards.com) — expressive web design, useful for visual ambition but often too heavy for product UI.
- [Minimal Gallery](https://minimal.gallery) — high-end minimal sites.
- [Hover States](https://hoverstat.es) — experimental interaction and web art.

## How To Use A Reference

Capture:

- What type of product or page it serves
- What layout structure it uses
- How density and spacing are handled
- How navigation works
- What type scale and contrast system it uses
- What interactions matter
- What would be inappropriate to copy

Then write an implementation direction in your own words.
