# Component And Library Sources

Prefer the existing project design system. Use these sources when the project lacks a suitable pattern, when the user asks for a new UI surface, or when a proven library prevents hand-rolled fragile behavior.

## General React UI

- [shadcn/ui](https://ui.shadcn.com) — strong default for accessible React primitives and copy-owned source.
- [Kibo UI](https://www.kibo-ui.com) — additional shadcn-compatible components.
- [Untitled UI](https://www.untitledui.com) — polished product and marketing component references.
- [21st.dev](https://21st.dev) — community components and agent-oriented discovery.
- [Uiverse](https://uiverse.io) — open-source UI elements; inspect quality and accessibility before use.

## Animated And Interaction-Heavy Components

- [Motion Primitives](https://motion-primitives.com) — interaction primitives for React.
- [Magic UI](https://magicui.design) — animated components and effects.
- [Aceternity UI](https://ui.aceternity.com) — animated React/Tailwind components.
- [SmoothUI](https://smoothui.dev) — animated components built with Motion and GSAP.
- [Planes](https://useplanes.com) — agent-ready React, Tailwind, and Motion component source.
- [Fluid Functionalism](https://fluidfunctionalism.com) — free interaction and UI reference source.
- [MicroKit](https://microkit.co) — small MIT React/Tailwind microinteractions.

## Sections And Blocks

- [shadcnblocks](https://www.shadcnblocks.com) — prebuilt section blocks for shadcn/ui.
- [Bencho](https://bencho.dev) — interactive UI and animated templates.
- [Motionsites](https://motionsites.ai) — animated site templates and interaction ideas.

## Motion Engines

- [Motion](https://motion.dev) — default choice for React motion and interaction.
- [GSAP](https://gsap.com) — complex timelines, scroll animation, and high-control motion.
- [Anime.js](https://animejs.com) — lightweight animation engine.
- [Remotion](https://www.remotion.dev) — programmatic video and motion design.

## 3D And Shaders

- [Three.js](https://threejs.org) — standard web 3D library.
- [React Three Fiber](https://r3f.docs.pmnd.rs) — React renderer for Three.js.
- [ShaderToy](https://www.shadertoy.com) — shader examples.
- [The Book of Shaders](https://thebookofshaders.com) — shader fundamentals.
- [Three.js Journey](https://threejs-journey.com) — deeper Three.js and shader education.

## Selection Rules

- Use a library when it reduces risk or enables a hard interaction.
- Avoid installing a dependency for a trivial button, card, or static layout.
- Check license before copying code into a public or client project.
- Preserve accessibility states when adapting visual components.
- For paid sources, only use them when the user already has access or explicitly asks to use them.
- Treat screenshots and galleries as references, not production code.
