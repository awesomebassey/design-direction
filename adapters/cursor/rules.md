# design-direction Cursor Rules

Use `skill.md` as the source of truth for product UI work.

Before implementing UI:

- Identify product context, user workflow, density, tone, and constraints.
- Prefer existing project components.
- Use real references and proven libraries for complex interactions.
- Avoid decorative overbuilding.
- Account for responsive, loading, empty, error, disabled, focus, and mobile states.
- Run or recommend UI stress tests from `references/qa-checklist.md`.

Use reference files only when they are relevant to the current task.
