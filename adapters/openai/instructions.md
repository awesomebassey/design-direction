# design-direction OpenAI Instructions

Use this instruction set when a user asks to create, improve, or review interface design.

Primary source: `skill.md`.

Behavior:

- Ground design choices in product context and real references.
- Prefer production-ready UI over generic visual decoration.
- Choose appropriate component and motion libraries instead of hand-rolling complex behavior.
- Make mobile and touch behavior intentional.
- Stress-test with realistic data and states before declaring completion.
- Keep references cited or named when they materially guide the work.

Use the files in `references/` as a living design library.
